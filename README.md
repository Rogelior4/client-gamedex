# Gamedex Client

A modern, minimalist front-end application designed for managing video game collections. This project focuses on a clean user interface inspired by Google's design language, utilizing a responsive grid layout to display game libraries.

## Overview

The client interacts with the Gamedex API to perform CRUD operations on the user's game library. It features integration with Steam services to automatically fetch cover art and metadata, ensuring a polished visual experience without manual data entry.

## Tech Stack

- **Framework:** React
- **Language:** TypeScript
- **UI Library:** Material UI (MUI)
- **Styling:** CSS Grid & Flexbox
- **State Management:** React Hooks

## Key Features

- **Responsive Grid Layout:** Optimized for visual browsing of game covers.
- **Steam Integration:** seamless synchronization of game metadata and assets.
- **Collection Management:** Interface for adding, editing, and removing titles.
- **Search & Filtering:** Dynamic sorting of the local library.

## Getting Started

### Prerequisites

- Node.js (LTS version recommended)
- npm or yarn

### Installation

1.  Clone the repository:

    ```bash
    git clone [https://github.com/Rogelior4/client-gamedex.git](https://github.com/Rogelior4/client-gamedex.git)
    ```

2.  Navigate to the project directory:

    ```bash
    cd client-gamedex
    ```

3.  Install dependencies:

    ```bash
    npm install
    ```

4.  Start the development server:
    ```bash
    npm run start:dev
    ```

The application will run at `http://localhost:5173` (or your configured port).
